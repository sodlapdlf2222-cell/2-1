# 스포츠 정보 웹사이트

## 대상 사용자

- 국내 야구, 농구, 배구 등 다양한 스포츠를 즐기는 사람
- 경기 결과와 선수 통계를 빠르게 확인하고 싶은 사람
- 자신이 응원하는 팀의 정보를 자주 보는 사람

## 사용 목적

- 선택한 종목과 팀의 경기 결과 확인
- 경기의 스코어와 선수 통계 조회
- 자주 보는 종목·팀 정보 저장 (재방문 시 유지)

## 화면 구성과 동작

### 메인페이지
- **종목 선택 버튼**: 야구, 농구, 배구 중 선택
- **팀 선택 버튼**: 선택한 종목의 팀 목록 표시 후 선택
- **동작**: 종목 → 팀 선택 후 "경기목록 보기" 버튼 클릭 → 경기목록 페이지로 이동
- **저장**: 선택한 종목·팀은 로컬스토리지에 저장되어 다음 방문 시 유지
- **디자인**: 밝은 톤 (흰색 배경, 파스텔 색상 버튼)

### 경기목록 페이지
- **표시 내용**: 선택한 팀의 경기 목록 (날짜, 상대팀, 스코어)
- **동작**: 각 경기 클릭 → 상세페이지로 이동
- **뒤로가기**: 메인페이지로 돌아가기
- **모바일 최적화**: 카드 형식으로 세로 배열

### 상세페이지
- **스코어**: 경기 결과 (팀명, 최종 스코어)
- **선수통계**: 주요 선수의 기본 통계 (이름, 포지션, 득점, 어시스트 등)
- **뒤로가기**: 경기목록 페이지로 돌아가기
- **모바일 최적화**: 세로 스크롤로 모든 정보 확인 가능

## 필요한 자료

- **샘플 데이터** (JSON 형식, HTML 내 포함)
  - 야구: KIA, LG, SSG, 두산, 롯데 (5개 팀)
  - 농구: SKT, KCC, 삼성, 현대캐피탈, 울산 (5개 팀)
  - 배구: GS칼텍스, 현대캐피탈, 한국전력, 대한항공, 삼성 (5개 팀)
  - 각 팀별 5경기 데이터
  - 각 경기별 주요 선수 통계 (이름, 포지션, 득점, 어시스트, 리바운드/세트/블로킹 등)

## 완료 기준

- [ ] 메인페이지에서 종목 선택 가능
- [ ] 종목 선택 후 팀 선택 가능
- [ ] 팀 선택 후 경기목록 표시 (날짜, 상대팀, 스코어)
- [ ] 경기 클릭 시 상세페이지 이동
- [ ] 상세페이지에 스코어 표시
- [ ] 상세페이지에 선수통계 표시 (이름, 포지션, 득점, 어시스트 등)
- [ ] 종목·팀 선택이 로컬스토리지에 저장되고 새로고침 후에도 유지
- [ ] 모바일에서도 잘 보임 (반응형 디자인)
- [ ] 밝은 톤 디자인 적용
- [ ] HTML 파일 하나로 열림 (외부 파일 없이 작동)

## 추가 기능

- 선수통계 상세 조회 (더 많은 항목)
- 하이라이트 영상 재생 (추후 목표)
- 실제 스포츠 API 연동 (추후 목표)

## 한계 및 비목표

1. 실시간 데이터 미지원: 샘플 데이터만 사용하므로 실제 경기 결과가 아님
2. **하이라이트 영상 미지원 (현재)**: 실시간 웹 검색이 불가능하여 현재 단계에서는 구현 불가능 (추후 목표)
3. 다중 사용자 미지원: 로컬스토리지 사용으로 한 기기에서만 저장 유지
4. 데이터베이스 미사용: 모든 데이터가 HTML에 포함되므로 대량 데이터 처리 불가
5. 실시간 업데이트 미지원: 페이지 새로고침 필요

## 검증 방법

- **메인페이지**: 종목 선택 후 해당 종목의 팀만 표시되는지 확인
- **경기목록**: 선택한 팀의 경기만 표시되는지 확인
- **상세페이지**: 클릭한 경기의 정확한 스코어와 선수통계가 표시되는지 확인
- **로컬스토리지**: 종목·팀 선택 후 새로고침 → 이전 선택이 유지되는지 확인
- **모바일 반응형**: 스마트폰 크기에서 레이아웃이 깨지지 않고 잘 보이는지 확인
- **디자인**: 밝은 톤이 일관되게 적용되었는지 확인
- **HTML 단일 파일**: 다른 파일 없이 HTML 파일만으로 모든 기능 작동하는지 확인

## 추후 목표

### 1단계: 하이라이트 영상 연동
- **목표**: 경기별 하이라이트 영상 제공
- **방식**: 유튜브 영상 ID를 샘플 데이터에 추가하여 임베드
- **현재 상태**: 불가능 (실시간 웹 검색 미지원)
- **해결 방안**: 실제 스포츠 하이라이트 영상을 수동으로 찾아 ID 할당

### 2단계: 실제 스포츠 API 연동
- **목표**: 실시간 경기 결과 및 선수 통계 제공
- **예상 API**: 야구(KBO), 농구(KBL), 배구(V-League) 공식 API
- **기대효과**: 샘플 데이터 대신 실제 데이터 사용
